# 배차간격 마트 임포트 리포트

30분 단위 평균 배차간격을 **환승 후 대기시간** 계산에만 사용한다.

```
headway_freq_min  = 30 / n_departures
expected_wait_min = headway_freq_min / 2   (균등 도착 가정)
```

## 검증

| check                            | status   | detail                                   |
|:---------------------------------|:---------|:-----------------------------------------|
| day_type 매핑                      | PASS     | ['saturday', 'sunday', 'weekday']        |
| direction 매핑                     | PASS     | ['down', 'inner', 'outer', 'up']         |
| line_id 범위                       | PASS     | ['1', '2', '3', '4', '5', '6', '7', '8'] |
| 운행 bin 의 expected_wait 가 0.1~60분 | PASS     | 이탈 0행                                    |
| 미운행 bin                          | WARN     | 5186행 (n_departures=0). 폴백 대상            |
| 그래프 역이 배차 데이터에 존재                | PASS     | 미포함 0개 []                                |

## 이번 MVP 의 범위와 한계

- **최초 승차 전 대기시간은 반영하지 않는다.** 사용자가 승강장에 도착하는 시점을 알 수 없어 출발 시각 입력의 의미가 흐려진다.
- 특정 시각의 실제 다음 열차 출발시각을 찾지 않는다. 30분 bin 평균이다.
- 균등 도착 가정(기댓값 = 배차간격/2)이며, 열차 지연·혼잡 시 승차 실패는 고려하지 않는다.
- 정밀 시각표 기반 next departure 계산은 다음 버전 과제로 남긴다.
