# 이벤트 효과 이중차분(DiD-lite) 리포트

05 의 spike_ratio 는 대조군 없는 전후 비교다. 그날 서울 전체 통행량이 많았다면 배율이 부풀려진다. 여기서는 대조군을 두고 순효과를 분리한다.

```
DiD = (처치군 변화) - (대조군 변화)
```

## 1. 대조군 선정 규칙

1. 어떤 이벤트의 anchor/impact 역도 아닌 역
2. **spillover 제외**: 같은 노선에서 3정거장 이내는 뺀다. 인파가 인접역으로 번지면 대조군이 오염되어 효과가 과소추정된다.
3. 평소 이용 규모(log 일평균)가 가장 가까운 5개
4. **평행추세 검증**: 이벤트 직전 4주 추세 차이가 0.15 이내면 가정 충족

## 7. 한계

- 회귀 기반 DiD 가 아니라 비율 차분 방식(DiD-lite)이다. 표준오차를 내지 않는다.
- 대조군은 규모 유사성만으로 매칭했다. 상권 성격·요일 패턴은 통제하지 않았다.
- 평행추세 판정 임계 0.15 는 근거 있는 상수가 아니라 초기값이다.
- spillover 는 같은 노선 3정거장 기준으로만 제외했다. 환승으로 이어진 다른 노선 역은 통제하지 못한다.
